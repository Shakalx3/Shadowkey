# Shadowkey — Nokia N95 compatibility research

Technical project to port The Elder Scrolls Travels: Shadowkey to Nokia N95 8GB RM-320 (Symbian OS 9.2 / S60 3rd Edition FP1). Target deliverable: modified executable and/or compatible DLLs; no SIS installer required. No real-device launch has been verified yet.
